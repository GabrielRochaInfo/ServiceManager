# 🔧 Service Manager

Aplicativo desenvolvido em Flutter para gerenciamento de clientes e ordens de serviço.

O objetivo do projeto é facilitar o controle de atendimentos técnicos, cadastro de clientes, acompanhamento de serviços e visualização de faturamento de forma simples e organizada.

---

## 📱 Funcionalidades

### 👥 Clientes
- Cadastro de clientes
- Edição de informações
- Exclusão de clientes
- Visualização de detalhes
- Histórico completo de serviços por cliente

### 🔧 Serviços
- Cadastro de ordens de serviço
- Edição de serviços
- Exclusão de serviços
- Controle de status
  - Em andamento
  - Concluído
- Associação de serviços aos clientes

### 📊 Dashboard
- Total de clientes cadastrados
- Total de serviços registrados
- Serviços concluídos
- Serviços pendentes
- Faturamento total
- Visualização dos últimos serviços realizados

## 🚀 Como Executar

### Clonar o projeto

```bash
git clone https://github.com/GabrielRochaInfo/ServiceManager.git
```

### Entrar na pasta

```bash
cd ServiceManager
```

### Instalar dependências

```bash
flutter pub get
```

### Executar

```bash
flutter run
```
